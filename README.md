# Kafene

Kafene is an offline-first workspace for Windows. It brings notes, databases, charts, and whiteboards into one local workspace and includes a local MCP bridge for coding agents.

- [Download Kafene for Windows](https://github.com/yash55-sop/KAFENE/releases/latest)
- [Connect Codex or Claude](https://kafene-desktop.yashwork0055.chatgpt.site/docs/)
- [Build the Windows installer](kafene-desktop/README.md)
